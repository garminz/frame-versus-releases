# FrameVersus

A desktop app for viewing and comparing images side by side, with zoom and pan that stay in sync across every pane. Free to use, including for commercial work. Available for macOS, Windows, and Linux.

## Download

**[Get the latest release →](https://github.com/garminz/frame-versus-releases/releases/latest)** and pick the file for your system from **Assets**:

| System | File |
|---|---|
| macOS, Apple Silicon | `_aarch64.dmg` |
| macOS, Intel | `_x64.dmg` |
| Windows 10 / 11 | `_x64-setup.exe` (or `.msi`) |
| Linux, Debian / Ubuntu | `.deb` |
| Linux, Fedora / RHEL / openSUSE | `.rpm` |
| Linux, any distribution | `.AppImage` |

Requires macOS 10.13+, Windows 10 or 11, or Linux with WebKitGTK 4.1 (Ubuntu 22.04+, Debian 12+, Fedora 38+).

## Features

- Carousel, Grid (up to 26 panes), and Overlay layouts
- Synced zoom and pan across linked panes
- Cursor-centric scroll zoom, drag to pan, and `Z` to toggle between 100% and fit
- EXIF overlays and per-image notes
- JPEG, PNG, WebP, and RAW previews (ARW, DNG, CR2, NEF and more, via the embedded JPEG; not a RAW processor)
- Export the current comparison as a JPEG
- Light, Dark Pro, and Darkroom themes

Press `?` in the app for all keyboard shortcuts.

## Privacy

FrameVersus runs entirely on your computer. It doesn't upload your images or collect usage data.
